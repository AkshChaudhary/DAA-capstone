# Mini Courier Planner

An algorithm-based courier delivery planning
system developed using Python.

## Project Objective

The objective is to optimize courier package
selection, vehicle loading and delivery routes
using Design and Analysis of Algorithms.

## Technologies

- Python
- CSV
- Visual Studio Code

## Algorithms Implemented

1. Adjacency Matrix
2. Adjacency List
3. Merge Sort
4. Insertion Sort
5. Greedy Approach
6. 0/1 Knapsack Dynamic Programming
7. Dijkstra Shortest Path
8. Bellman-Ford Algorithm
9. Nearest Neighbor Approximation

## Project Phases

| Phase | Description |
|---|---|
| 1 | Design and Planning |
| 2 | Package Prioritization and Vehicle Loading |
| 3 | Route Master and Traffic Processing |
| 4 | Performance Testing and Optimization |
| 5 | Final Report and Demonstration |

## Sample Results

- Locations: 6
- Roads: 7
- Vehicle Capacity: 15 kg
- Selected Packages: 4
- Loaded Weight: 14 kg
- Total Benefit: 370
- Delivery Route Distance: 15 km

## How to Run

```bash
python main.py
python phase2.py
python phase3.py
python phase4.py
python phase5.py
```

Run each command from the project root.

## Output

Generated reports are saved in the output
directory.

This version uses predefined demonstration
