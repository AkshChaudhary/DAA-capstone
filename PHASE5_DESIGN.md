# MINI COURIER PLANNER
## Phase 5: Final Report and Demonstration

### 1. Introduction

Phase 5 presents the completed Mini Courier
Planner project and its algorithm implementations.

### 2. Project Overview

The system plans courier deliveries using
graph algorithms, sorting techniques,
Greedy Approach and Dynamic Programming.

### 3. Completed Project Phases

Phase 1: Design and Planning

Phase 2: Package Prioritization and Vehicle Loading

Phase 3: Route Master and Traffic Processing

Phase 4: Performance Testing and Optimization

Phase 5: Final Report and Demonstration

### 4. Final Results

Locations: 6

Roads: 7

Selected Packages: 4

Vehicle Capacity: 15 kg

Loaded Weight: 14 kg

Total Benefit: 370

Optimized Delivery Distance: 15 km

### 5. Demonstration

The project demonstration covers:

- Graph representation
- Package sorting
- Knapsack optimization
- Dijkstra shortest paths
- Bellman-Ford negative cycle detection
- Nearest Neighbor delivery planning
- Performance analysis

### 6. Performance Evaluation

Multiple dataset sizes were tested.

Execution time was measured using
Python time.perf_counter().

Median execution time was recorded.

### 7. Limitations

- Uses sample road distances.
- No live traffic API integration.
- Uses a predefined package dataset.
- Nearest Neighbor is an approximation.

### 8. Future Enhancements

- Live traffic integration.
- Interactive route maps.
- Multiple vehicle optimization.
- Real-time delivery tracking.

### 9. Conclusion

The Mini Courier Planner successfully
demonstrates the application of Design
and Analysis of Algorithms to courier
package selection, vehicle loading and
route planning.
